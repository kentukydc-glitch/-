# Проверка Lucru из вашей сети на macOS

GitHub-серверы получают отказ Lucru, а в обычном браузере на Mac сайт
открывается. Отдельный runner позволит проверить сбор из той же сети.
Это проверка доступа, а не утверждение, что локальный автоматический сбор
уже работает. Подключение к недельной рассылке будет следующим шагом
после проверки настоящих данных и даты публикации.

## Один раз подключить Mac

1. Откройте https://github.com/kentukydc-glitch/-/settings/actions/runners/new
   и выберите macOS. Для Apple Silicon (M1/M2/M3/M4 и новее) выберите ARM64;
   для Intel — x64. Тип можно посмотреть: меню Apple → «Об этом Mac».
2. Откройте «Терминал». Выполните команды из разделов **Download** и
   **Configure** на странице GitHub. Используйте именно показанные GitHub
   команды скачивания и проверки контрольной суммы. При настройке можно
   принять имя и метки по умолчанию клавишей Enter.
3. Запустите `./run.sh` из папки runner и оставьте Терминал открытым.
   Mac должен быть включён, подключён к сети, с открытой пользовательской
   сессией; автоматический сон на время проверки нужно отключить.

Регистрационный токен копируйте только со страницы GitHub в Терминал своего
Mac, не отправляйте в чат. Пароль Gmail для этой проверки не нужен.

## Выполнить проверку

После подключения Mac сообщите в чате «runner подключён» — проверку можно
будет запустить из чата через отдельную ветку, без отправки писем.

Откройте https://github.com/kentukydc-glitch/-/actions/workflows/lucru-mac.yml
и нажмите **Run workflow → main → Run workflow**.

На Mac откроется отдельное окно Chromium. Вход в личный кабинет Lucru
не требуется. Сборщик не копирует cookies обычного браузера и не решает
CAPTCHA автоматически. Отдельный профиль Chromium сохраняется на Mac
в каталоге tool cache runner.

Письма не отправляются: workflow не получает SMTP-пароль. Результат появится
в артефакте **lucru-mac-check** и в ветке **lucru-mac-report**.
В недельную подборку проходят только объявления с явной датой публикации
`JobPosting.datePosted`; дата сбора и обновления её не заменяет.

После проверки runner можно остановить в Терминале сочетанием Control+C.
Расписание Mac пока не включено; действующая облачная рассылка сохраняется.
