# Правила еженедельной подборки вакансий

- Колонка «Дата публикации» содержит только явно указанную источником дату
  публикации вакансии. Текущий подтверждённый источник этого значения —
  `JobPosting.datePosted`.
- Даты обновления, поднятия, индексации и сбора не заменяют дату публикации.
  Относительные метки «Publicat azi», «Publicat ieri», «сегодня» и «вчера»
  сами по себе не подтверждают первоначальную публикацию.
- Без подтверждённой даты публикации вакансия не включается в подборку новых
  объявлений за неделю. Не угадывать дату по ID объявления или поисковой выдаче.
- В отчёте указывать количество записей с неизвестной датой. Любое расширение
  источников даты должно сохранять это правило и сопровождаться проверками.
- Рабочие источники: Delucru.md, Jobber.md, 999.md и Lucru.md.
  Lucru собирается на Mac; используются только проверенные данные не старше
  24 часов, иначе источник отмечается недоступным. Дата сбора кеша не является
  датой публикации вакансии. TopAngajatori и Muncitorul исключены пользователем.
