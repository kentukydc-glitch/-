# AI Lawyer

Первый репозиторий проекта.

## Еженедельные вакансии юриста

Python 3.12 и Playwright 1.56.0 с Chromium для сайтов с JavaScript. Источники: Lucru.md,
Delucru.md, Jobber.md и 999.md. Lucru.md проверяется отдельно, доступ может быть ограничен.
Получатель: kentukydc@gmail.com. Расписание: понедельник, 09:00
Europe/Chisinau (GitHub может запускать задания с задержкой).

### Включение

1. Загрузите изменения в основную ветку GitHub и включите Actions.
2. В Settings → Secrets and variables → Actions добавьте секрет
   `SMTP_PASSWORD`: пароль приложения Gmail для kentukydc@gmail.com.
   В workflow уже указаны smtp.gmail.com, порт 587 (STARTTLS), отправитель и логин
   kentukydc@gmail.com. Для другого аккаунта измените workflow.
   Создание пароля приложения требует двухэтапной аутентификации.
   Обычный пароль аккаунта в проект не добавляйте.
3. Запустите Weekly legal vacancies через Run workflow. По умолчанию
   это проверка без отправки: SMTP не нужен. Скачайте артефакт digest-report
   и проверьте digest.html и report.json. Для реального письма включите
   Send email после настройки SMTP-секретов.
4. Workflow хранит историю доставленных URL в отдельной ветке digest-state.
   Разрешите Actions запись в репозиторий; правила веток могут запрещать её.

### Локальная проверка

```sh
python3 -m pip install -r requirements.txt
python3 -m playwright install --with-deps chromium
python3 -m unittest discover -s tests -v
python3 collector.py
```

Второй вызов сохраняет output/digest.html и output/report.json без отправки
и без изменения истории. Для отправки задайте SMTP-переменные окружения
и используйте `python3 collector.py --send`.

### Ограничения текущей версии

Сборщик соблюдает robots.txt и использует обычный Chromium для сайтов,
которые загружают объявления через JavaScript. Защиту сайта и CAPTCHA он
не обходит. Текущие источники:

- **Delucru.md:** HTML юридических вакансий.
- **Jobber.md:** браузерный поиск `jurist`, отбор юридических должностей,
  структурированные данные работодателя и даты публикации. Русские,
  румынские и английские названия юридических должностей поддерживаются.
- **999.md:** отдельный раздел вакансий «Jurist, consilier juridic»,
  только JobPosting. Резюме и предложения юридических услуг не включаются.
- **Lucru.md:** проверяется, но при текущем отказе доступа 403 отмечается
  недоступным. Успешная проверка остальных источников это не скрывает.

Каждый источник ограничен 12 страницами за запуск. Полнота охвата всех
объявлений не гарантируется. Отчёт различает проверенную страницу без
подходящих вакансий и ошибку доступа или разбора.

Результаты: `output/digest.html`, `output/vacancies.csv`,
`output/vacancies.json`, `output/report.json`. Каждый запуск публикует отчёт
также в ветку `collection-report`; её содержимое не является исходным кодом.
Регулярное расписание GitHub работает в основной ветке. При push в main
или automation/legal-digest сбор выполняется без отправки почты.

Включаются объявления с датой за последние 7 дней либо явно отмеченные
объявления без даты, впервые обнаруженные сборщиком. При первом запуске
отправляется подборка за неделю, затем исключаются уже отправленные URL.
Описание требований — выдержка до 350 символов, без генерации фактов.
Повторы с одинаковым URL исключаются; разные сайты и изменённые URL могут
содержать одну вакансию. Ошибки источников включаются в письмо; ошибки всех
источников дополнительно завершают задание с ошибкой.

История сохраняется после принятия письма SMTP-сервером. Если письмо принято,
а сохранение истории в GitHub не удалось, повторный запуск может повторить
рассылку. Принятие SMTP-сервером не гарантирует доставку во входящие.
